# Anonimizador

Aplicación de escritorio (macOS y Windows) que anonimiza documentos Word y PDF
—incluidos PDFs escaneados— de forma **100% local**, para poder consultarlos con una IA
sin exponer datos de clientes.

- El usuario indica qué nombres sustituir y por qué.
- La app detecta además DNI, IBAN, empresas, direcciones, etc., y sugiere sustitutos.
- Nada sale del equipo.

Estado: en desarrollo. Ver [docs/PROGRESO.md](docs/PROGRESO.md).
